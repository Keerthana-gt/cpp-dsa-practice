# LRU Cache in C++

## 📌 Overview
This project implements an **LRU (Least Recently Used) Cache** using a **hash map** and a **doubly linked list**.  
It supports constant‑time `get()` and `put()` operations, ensuring efficient cache management.

---

## ⚙️ Features
- O(1) time complexity for `get()` and `put()`
- Automatic eviction of least recently used items
- Configurable cache capacity
- Unit tests included

---

## 🛠️ Tech Stack
- Language: **C++**
- Data Structures: **Hash Map + Doubly Linked List**
- Build: **Makefile**

---
